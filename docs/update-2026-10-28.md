# Daily cadence, fuller perspectives and usage guides

This update adds daily cadence controls, fuller perspectives and usage guides.

- Daily briefs default to every day at 07:30; weekly perspectives remain Sunday at 09:00 with a seven-day guard. Updating source never rewrites existing configurations or their explicit intervals.
- Each commentator can have a position, evidence, reasoning and counterpoint. Research should support the added detail; inaccessible or short sources must stay short and disclose the limit.
- Public funding context is optional and bounded. Labels distinguish personal ties from organization ownership, donors or revenue, preserve unknown states, and require citations for documented claims. Organization funding is not evidence that a particular author or statement was paid for.
- The renderer and copy prompts carry the new context. Existing simple briefs remain compatible.
- Existing archives can be rerendered without rerunning providers. The repository and demo website contain only synthetic example briefs.
- The author's introduction remains empty in `content/introduction.json`. The homepage contains no substitute marketing introduction. English/Chinese usage guides are supplied separately through `content/usage.json` and generated as `usage.en.html` / `usage.zh.html`.

At this update, local verification passed 19 automated tests, the bilingual CLI smoke, syntax and privacy checks. Public builds contain only synthetic fixtures, the empty author-owned introduction and usage instructions.

Running question servers need a restart to load the new server prompt; already generated pages need rerendering for updated copy context. Updating source files alone does not reload a running Node process. Live provider research/answers and delivered notifications were not invoked by the code tests.
