# Daily cadence, fuller perspectives and usage guides

This update implements the user's next requirements in the existing project.

- Daily briefs default to every day at 07:30; weekly perspectives remain Sunday at 09:00. Existing private configurations using an interval of 3 must explicitly change to 1. The personal installer uses the same daily cadence.
- Each commentator can have a position, evidence, reasoning and counterpoint. Research should support the added detail; inaccessible or short sources must stay short and disclose the limit.
- Public funding context is optional and bounded. Labels distinguish personal ties from organization ownership, donors or revenue, preserve unknown states, and require citations for documented claims. Organization funding is not evidence that a particular author or statement was paid for.
- Both local and public renderers/copy prompts carry the new context. Existing simple briefs remain compatible.
- Existing local archives can be rerendered without rerunning providers. Any source-checked supplements, real news and personal output remain local and are excluded from the repository and website.
- The author's introduction remains empty in `content/introduction.json`. The homepage contains no substitute marketing introduction. English/Chinese usage guides are supplied separately through `content/usage.json` and generated as `usage.en.html` / `usage.zh.html`.

Independent read-only review found no material blockers in the code delta or the local source-checked supplement. Local verification passed 19 OSS tests, the bilingual CLI smoke, syntax and privacy checks, plus 23 personal-renderer CLI cases and copy/ask prompt-builder assertions. Public builds contain only synthetic fixtures, the empty author-owned introduction and usage instructions.

Running personal question servers need a restart to load the new server prompt; already generated pages need rerendering for updated copy context. Updating source files alone does not reload a running Node process. Live provider research/answers and delivered notifications were not invoked by the code tests.
